# ImgHost

Una herramienta todo en uno para alojar contenido personal, basada en el ecosistema Cloudflare.

ImgHost empezó con la subida de imágenes y la gestión de enlaces. Hoy ha crecido hasta convertirse en una solución completa para alojar contenido personal. Con ImgHost puedes:

- Subir archivos a cualquier canal de almacenamiento que prefieras
- Compartir públicamente imágenes y archivos de cualquier formato
- Montar un blog personal en un minuto
- Guardar archivos desde enlaces magnet con un solo clic
- Unirte a la federación de nodos ImgHost y compartir índices de archivos abiertos

Nuestra idea inicial es que cualquier persona pueda tener su propio sitio para alojar imágenes y compartir archivos. No importa de qué país seas ni qué idioma uses: si solo quieres guardar imágenes, organizar álbumes, compartir archivos con amigos, o crear un espacio de alojamiento estable para un blog, contenido creativo o recursos públicos, ImgHost busca reducir la barrera de entrada tanto como sea posible y hacer que todo sea más libre, más claro y más fácil de empezar.

## Potencia lista para usar

- 🌍 28 idiomas de interfaz para usuarios de todo el mundo
- 📦 13 canales de subida principales integrados: Telegram, Cloudflare R2, S3, WebDAV, Discord, Hugging Face, GitHub Releases, GitLab Packages, OneDrive, Google Drive, Dropbox, Yandex y pCloud
- 🧩 Diseño completamente modular: activa solo lo que necesitas y evita gastar recursos de más
- 🔐 Admite API Token, modos de acceso y reglas de listas para gestionar permisos de contenido con precisión

Este proyecto sigue mejorando. Nuestra capacidad es limitada, pero haremos todo lo posible para que cada función sea clara, estable y fácil de usar. Si ImgHost te ayuda a tener con menos esfuerzo tu propio alojamiento de imágenes, blog o espacio para compartir archivos, nos hará muy felices.
