# ImgHost

An all-in-one personal content hosting tool built on the Cloudflare ecosystem.

ImgHost started with image uploads and link management. It has now grown into a complete personal content hosting solution. You can use it to:

- Upload files to any storage channel you prefer
- Publicly share images and files of any format
- Set up a personal blog in one minute
- Save files from magnet links with one click
- Join the ImgHost node federation and share open file indexes

Our original goal is to help everyone have their own image hosting and file sharing site. No matter which country you are from or which language you use, whether you simply want to save images, organize albums, share files with friends, or build a stable hosting space for a blog, creative work, or public resources, ImgHost aims to lower the barrier as much as possible and make the experience freer, clearer, and easier to start.

## Powerful Features Out of the Box

- 🌍 28 interface languages for users around the world
- 📦 13 built-in mainstream upload channels: Telegram, Cloudflare R2, S3, WebDAV, Discord, Hugging Face, GitHub Releases, GitLab Packages, OneDrive, Google Drive, Dropbox, Yandex, and pCloud
- 🧩 Fully modular design, so every feature can be enabled only when needed
- 🔐 Supports API Token, access modes, and list rules for fine-grained content permission management

This project is still being improved. Our ability is limited, but we will do our best to make every feature clear, stable, and pleasant to use. If ImgHost helps you own your own image host, blog, or file sharing space more easily, we will be very happy.
