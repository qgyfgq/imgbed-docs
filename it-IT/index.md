# ImgHost

Uno strumento completo per ospitare contenuti personali, basato sull'ecosistema Cloudflare.

ImgHost è nato per caricare immagini e gestire link. Oggi è cresciuto fino a diventare una soluzione completa per l'hosting di contenuti personali. Puoi usarlo per:

- Caricare file su qualsiasi canale di archiviazione tu preferisca
- Condividere pubblicamente immagini e file di qualsiasi formato
- Creare rapidamente un blog personale in un minuto
- Salvare file da link magnet con un solo clic
- Entrare nella federazione dei nodi ImgHost e condividere indici di file aperti

Il nostro obiettivo iniziale è permettere a chiunque di avere un proprio sito per ospitare immagini e condividere file. Non importa da quale Paese vieni o quale lingua usi: che tu voglia solo salvare immagini, organizzare album, condividere file con gli amici, oppure creare uno spazio di hosting stabile per un blog, contenuti creativi o risorse pubbliche, ImgHost cerca di abbassare il più possibile la soglia di accesso e rendere tutto più libero, più chiaro e più facile da iniziare.

## Funzionalità potenti pronte all'uso

- 🌍 Supporto a 28 lingue dell'interfaccia per utenti in tutto il mondo
- 📦 13 canali di caricamento principali integrati: Telegram, Cloudflare R2, S3, WebDAV, Discord, Hugging Face, GitHub Releases, GitLab Packages, OneDrive, Google Drive, Dropbox, Yandex e pCloud
- 🧩 Design completamente modulare: abiliti solo le funzioni che ti servono, senza sprecare risorse
- 🔐 Supporta API Token, modalità di accesso e regole di lista per gestire in modo granulare i permessi dei contenuti

Questo progetto continua a migliorare. Le nostre capacità sono limitate, ma faremo del nostro meglio per rendere ogni funzione chiara, stabile e piacevole da usare. Se ImgHost ti aiuta ad avere più facilmente il tuo spazio per ospitare immagini, blog o file condivisi, ne saremo molto felici.
