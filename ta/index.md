# ImgHost

Cloudflare சூழலை அடிப்படையாகக் கொண்ட, தனிப்பட்ட உள்ளடக்கங்களைத் தங்கவைக்கும் முழுமையான கருவி.

ImgHost படம் பதிவேற்றம் மற்றும் இணைப்பு மேலாண்மையிலிருந்து தொடங்கியது. இப்போது இது தனிப்பட்ட உள்ளடக்கத் தங்குதளத்திற்கான முழுமையான தீர்வாக வளர்ந்துள்ளது. இதை நீங்கள் பயன்படுத்த முடியும்:

- நீங்கள் விரும்பும் எந்த சேமிப்பு சேனலிற்கும் கோப்புகளைப் பதிவேற்ற
- படங்களையும் எந்த வடிவிலான கோப்புகளையும் பொதுவாகப் பகிர
- ஒரு நிமிடத்தில் தனிப்பட்ட வலைப்பதிவை விரைவாக அமைக்க
- காந்த இணைப்புகள் மூலம் கோப்புகளை ஒரே கிளிக்கில் சேமிக்க
- ImgHost முனைய கூட்டமைப்பில் சேர்ந்து திறந்த கோப்பு குறியீடுகளைப் பகிர

ஒவ்வொருவருக்கும் தங்களுக்கே உரிய படம் ஹோஸ்டிங் மற்றும் கோப்பு பகிர்வு தளம் இருக்க வேண்டும் என்பதே எங்கள் ஆரம்ப நோக்கம். நீங்கள் எந்த நாட்டைச் சேர்ந்தவராக இருந்தாலும், எந்த மொழியைப் பயன்படுத்தினாலும்; படங்களை எளிதாக சேமிக்க, ஆல்பங்களை ஒழுங்குபடுத்த, நண்பர்களுடன் கோப்புகளைப் பகிர, அல்லது வலைப்பதிவு, படைப்புப் உள்ளடக்கம், பொதுப் பயனுள்ள வளங்கள் ஆகியவற்றுக்கான நிலையான ஹோஸ்டிங் இடத்தை அமைக்க விரும்பினாலும், ImgHost தொடங்கும் தடையை முடிந்தவரை குறைத்து, இதை மேலும் சுதந்திரமான, தெளிவான, எளிதில் தொடங்கக்கூடிய அனுபவமாக மாற்ற விரும்புகிறது.

## உடனே பயன்படுத்தக்கூடிய சக்திவாய்ந்த திறன்கள்

- 🌍 உலகளாவிய பயனர்கள் எளிதாகப் பயன்படுத்த 28 இடைமுக மொழிகள் ஆதரவு
- 📦 உள்ளமைந்த 13 முக்கிய பதிவேற்ற சேனல்கள்: Telegram, Cloudflare R2, S3, WebDAV, Discord, Hugging Face, GitHub Releases, GitLab Packages, OneDrive, Google Drive, Dropbox, Yandex, pCloud
- 🧩 முழுமையான கூறு அடிப்படையிலான வடிவமைப்பு; தேவையான அம்சங்களை மட்டும் இயக்கலாம், வளங்கள் வீணாகாது
- 🔐 API Token, அணுகல் முறை மற்றும் பட்டியல் விதிகளை ஆதரிக்கிறது; உள்ளடக்க அனுமதிகளை நுணுக்கமாக நிர்வகிக்க உதவும்

இந்தத் திட்டம் தொடர்ந்து மேம்படுத்தப்படுகிறது. எங்கள் திறன் வரம்புடையது, ஆனால் ஒவ்வொரு அம்சத்தையும் தெளிவான, நிலையான, பயன்படுத்த எளிதானதாக உருவாக்க முழு முயற்சி செய்வோம். ImgHost உங்கள் சொந்த படத் தங்குதளம், வலைப்பதிவு அல்லது கோப்பு பகிர்வு இடத்தை எளிதாகப் பெற உதவினால், எங்களுக்கு மிகவும் மகிழ்ச்சி.
