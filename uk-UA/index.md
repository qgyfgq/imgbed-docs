# ImgHost

Універсальний інструмент для особистого хостингу контенту на базі екосистеми Cloudflare.

ImgHost починався із завантаження зображень і керування посиланнями. Тепер він виріс у повноцінне рішення для особистого хостингу контенту. Ви можете використовувати його, щоб:

- Завантажувати файли в будь-який бажаний канал зберігання
- Публічно ділитися зображеннями та файлами будь-якого формату
- Швидко розгорнути особистий блог за одну хвилину
- Одним кліком зберігати файли з magnet-посилань
- Приєднатися до федерації вузлів ImgHost і спільно використовувати відкриті індекси файлів

Наша початкова мета — допомогти кожному мати власний сайт для хостингу зображень і обміну файлами. Неважливо, з якої ви країни та якою мовою користуєтеся; чи хочете ви просто зберігати зображення, впорядковувати альбоми й ділитися файлами з друзями, чи створити стабільний простір для блогу, творчих матеріалів або публічних ресурсів, ImgHost прагне максимально знизити поріг входу й зробити цей досвід вільнішим, зрозумілішим і простішим для початку.

## Потужні можливості одразу з коробки

- 🌍 Підтримка 28 мов інтерфейсу для користувачів у всьому світі
- 📦 13 вбудованих основних каналів завантаження: Telegram, Cloudflare R2, S3, WebDAV, Discord, Hugging Face, GitHub Releases, GitLab Packages, OneDrive, Google Drive, Dropbox, Yandex і pCloud
- 🧩 Повністю модульний дизайн: кожну функцію можна вмикати за потреби, не витрачаючи ресурси даремно
- 🔐 Підтримує API Token, режими доступу та правила списків для точного керування правами на контент

Проєкт і далі вдосконалюється. Наші можливості обмежені, але ми зробимо все можливе, щоб кожна функція була зрозумілою, стабільною та зручною. Якщо ImgHost допоможе вам легше мати власний хостинг зображень, блог або простір для обміну файлами, ми будемо дуже раді.
